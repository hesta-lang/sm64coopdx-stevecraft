# SteveCraft 64 DynOS actor\n\nFast64-Gart export of Steve's cuboid body, rigged to the SM64CoopDX player armature. The standard player animations drive the head, torso, arms and legs.\n\nThe arms use a turquoise sleeve block and a skin-tone hand block. The independent first-person viewmodel is generated under actors/steve_hand/.\n\nSM64CoopDX reads these source files and generates the runtime DynOS .bin resources when the mod pack loads. Unsupported CUSTOM_CMD placeholders are removed before the source is committed.\n
