# SteveCraft direct Bedrock DynOS actor

Generated directly from Bedrock Geometry JSON by tools/build_steve_dynos.py. The model uses native DynOS C display lists and small per-face RGBA PNG textures; Blender and Fast64 are not used by this build path.

The existing Mario-compatible GeoLayout remains the animation compatibility layer. The Bedrock bone tree is included in the build report, but this alpha does not replace the Mario animation rig with a native 17-bone Bedrock rig.
