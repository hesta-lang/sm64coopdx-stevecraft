# SteveCraft 64 DynOS actor\n\nMinecraft Java 1.21.11 PlayerModel geometry and classic 64x64 Steve skin, rigged to the SM64CoopDX player armature.\n\nThe export retains the base cubes and all four outer-layer groups: hat, jacket, sleeves and pants. The original skin UVs are split into small per-cuboid textures to fit the N64 texture memory limits.\n\nThe generated GeoLayout is aligned to the 20-node Minecraft animation rig, including the zero-offset left and right wrist joints.\n\nThe independent first-person viewmodel is generated under actors/steve_hand/.\nSM64CoopDX generates runtime DynOS resources when the mod pack loads.\n
