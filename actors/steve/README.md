# SteveCraft 64 DynOS actor

Fast64-Gart export of Steve's cuboid body, rigged to the SM64CoopDX player armature. The standard player animations drive the head, torso, arms and legs.

The independent first-person actor steve_hand_geo is generated by tools/build_steve_hand.py from assets/steve/steve_skin.png. It uses the classic 4×12×4 Steve arm and original 64×64 skin UV coordinates.

DynOS reads these source files and generates runtime .bin resources when the mod pack loads. Unsupported CUSTOM_CMD() placeholders are removed by the body-model build script.
