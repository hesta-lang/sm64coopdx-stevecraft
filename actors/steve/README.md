# SteveCraft 64 DynOS actor

Fast64-Gart export of the classic six-part Steve body, rigged to the SM64CoopDX player armature. The base game animation set drives the head, torso, arms and legs.

Install this folder as mods/sm64coopdx-stevecraft/actors/steve/. SM64CoopDX builds steve_geo.bin when loading the actor.
