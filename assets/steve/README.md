# Steve source mesh

`steve_reference.obj` is a simple six-piece cuboid mesh for the classic Steve silhouette:

- Head
- Torso
- Left arm
- Right arm
- Left leg
- Right leg

It is a geometry reference for Blender/Fast64 rigging. It is **not** a ready-to-load SM64CoopDX player model. The mesh must be attached to the compatible SM64 player armature and exported as a DynOS GeoLayout resource.

The simple material colors are placeholders. A later pass should replace them with the pixel texture atlas and correct UVs for the classic Steve skin.
